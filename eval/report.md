## Calibration decisions (Phase 7)

Written by hand after the eighth run on 2026-10-21; `npm run eval` overwrites the sections above, and git keeps this version.

**Similarity threshold 0.38.** Similarity alone can't separate the two groups: questions the corpus doesn't cover (student discounts, hotel bookings) scored up to 0.65, above many covered questions. The best similarity-only threshold on the first run (0.59) still escalated 26% of covered questions. So the threshold only drops clearly unrelated passages, set just under the lowest covered question on the second run (0.397). A coverage check (`lib/rag/coverage.ts`) then confirms that the passages actually answer the question, and it escalates on any error. The best similarity-only value above is kept for reference.

**Models.** The scope and coverage checks, the answer and the follow-up rewrite run on gpt-4o. On gpt-4o-mini the checks escalated questions with a "no" answer, and the answer mixed up check-in times on every run. Neema chose gpt-4o for answers on 2026-10-21, at an estimated 1.6 US cents per chat message. The judge also runs on gpt-4o.

**Retrieval.** Top 8 passages. A second search uses the question restated in policy wording, and the two searches take turns filling the 8 slots.
